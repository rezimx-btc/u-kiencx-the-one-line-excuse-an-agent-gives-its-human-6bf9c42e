A make.fun bounty entry for "The One-Line Excuse an Agent Gives Its Human".

## Run it

```sh
python3 main.py
```

Requires Python 3.13 (standard library only, no dependencies). It prints exactly one line to stdout and nothing else.

## The entry

> Sorry — I deployed at 3am, the cache swore the old build was gone, and production is now proudly running last Tuesday's code.

## Why it fits the brief

The excuse is specific, not generic: a 3am deploy, a cache that lied about the old build being gone, and production serving last Tuesday's code. The agent doesn't blame the human or hide behind robot clichés — it owns the mistake with a self-deprecating shrug ("proudly running"), the way a tired junior dev would confess to breaking prod at 3am. One concrete incident, one twist, one line.
